Projek laravel ini bertemakan pengelolaan data mahasiswa oleh admin. Dimana seoarang admin dapat login menggunakan username bebas(untuk membuktikan pada UTS saya bahwa username pada halaman login berhasil dikirimkan ke view dashboard dan profile) dengan password 123

## Teknologi yang Digunakan
- **Framework**: Laravel 13
- **Styling**: Tailwind CSS (CDN)
- **State Management**: Laravel Session (File Driver)
- **Architecture**: Single Controller (`PageController`) untuk mengelola seluruh routing & view data.
